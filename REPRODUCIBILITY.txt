重現範圍與必要輸入
==================

本包把「可在乾淨 checkout 完成的驗證」與「需要原始資料／研究快取的完整重現」明確分開。
程式副本位於 project/，原始工作目錄為 /home/114/jim5528/ml2026。
每個原程式以自身目錄當 ROOT，因此資料／模型應放在 project/data 與 project/artifacts。

1. 不需競賽資料的檢查

  python3 scripts/verify_package.py
  cd project
  <Python 3.13 environment>/bin/python -m pytest -q

verify_package.py 以標準函式庫核對程式及證據來源雜湊、兩份 CSV 的格式／ID／價格、公開分數比較、年度改善與安置住宅測試表。
pytest 的 46 項合成測試覆蓋日期解析、時間標籤隔離、類別編碼、分組、選模門檻、安置戶排除與無查表推論。
這些檢查不是重新測量 test MAE；test 真實價格並未提供。

2. 環境

原研究使用 Python 3.13、CatBoost 1.2.10、LightGBM 4.7.0、scikit-learn 1.9.1。
完整固定相依套件版本見 project/requirements.lock.txt。
CatBoost 主訓練設定使用 NVIDIA GPU；CPU 訓練及不同 GPU 重訓不保證位元組相同。
保存模型重新推論已驗證能重現最終 CSV；沒有把 GPU 重訓的 bitwise reproducibility 當成保證。

4. 原模型推論／診斷重現

需先還原原研究的完整 artifacts/ 與必要歷史 CSV 至 project/，其預期雜湊由下列檔案列出：
  evidence/geography_v1/config.json
  evidence/geography_v1/audit_verification.json
  evidence/overfitting_v7/input_inventory.json
  evidence/policy_generalization_v1/protected_inventory.json

還原後在 project/ 執行：
  OMP_NUM_THREADS=12 OPENBLAS_NUM_THREADS=1 python verify_geography.py
  OMP_NUM_THREADS=8 OPENBLAS_NUM_THREADS=1 python audit_overfitting_v7.py
  OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=1 python audit_policy_generalization.py

verify_geography.py 從原始 test 重建特徵、載入模型並核對 v7，沒有重新 fitting 房價模型。
audit_policy_generalization.py 會另外 fitting 診斷模型，但不替換 v6/v7 的保存模型或 CSV。
部分舊 joblib 使用 __main__.ProjectIdentityMasker，載入時需先匯入原 train_generalization.ProjectIdentityMasker；audit_overfitting_v7.py 已處理。

5. 訓練來源與依賴順序

本專案保留逐輪凍結的研究程式，而不是宣稱有未經驗證的一鍵全量訓練命令：
  prepare.py → train.py / finalize_mae.py
  train_robust.py / select_robust.py
  train_spatial.py / train_hedonic.py / select_hedonic.py
  train_transfer.py / train_shift.py / select_shift.py
  policy_tables.py / train_policy_learned.py
  train_generalization.py
  geography_features.py / train_geography.py

各輪需要前輪的特徵、凍結迭代數、選擇紀錄與模型；不能直接在沒有快取的目錄執行最末一輪。
各程式 --help 與 evidence/ 中的 config / selection 提供實際設定。
若換資料來源或改核心程式，應另開實驗目錄，不修改原凍結設定以通過雜湊檢查。
